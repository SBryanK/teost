# Career Development Playbook

Interactive career-development website based on workshop notes with Benjamin Koh & May Koh.

Covers personal branding, LinkedIn optimisation, VIPS, networking, communication, job-search pipeline, CAR/STAR, cover letters, and interview preparation.

Interactive tools: LinkedIn headline builder, VIPS reflection, CAR/STAR story builder, and application tracker.

The site is deployed through GitHub Pages using the workflow in `.github/workflows/pages.yml`.
